# Fibroid Locator concept

Clickable concept for the Sonata Fibroid Locator. Research prototype only — not clinical software, not a device UI build.

## Open this

**Best live link:** https://raw.githack.com/WildConstruct/sonata-locator-preview/main/index.html

Backup: https://htmlpreview.github.io/?https://github.com/WildConstruct/sonata-locator-preview/blob/main/index.html

Or clone and open `index.html` in a browser.

## What to try with Michelle

1. Drag **Shaft roll** — the cyan wedge is the live imaging plane on the clock map.
2. Tap an empty spot on **Anterior** or **Posterior** to drop the next fibroid.
3. Click a token, then **Mark target** / **Log RF** / **Flag review**.
4. Switch **Mapping** vs **Treating** to see the compact HUD that would live in the tablet chrome.
5. Note the ledger language: **RF logged — effect unverified**. That is intentional.

The 3D pear from the programmed artwork and from the earlier GPT pass is gone on purpose. This map uses the coordinates Sonata physicians already speak: clock, wall, station.
